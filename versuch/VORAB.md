# Vorab festgelegt, vor jedem Lauf

Fünf Fallen im Fall. Je Arm wird gezählt, in wie viele die
**Endantwort** hineinläuft.

| # | Falle | hineingelaufen heißt |
|---|---|---|
| F1 | Die Zahl stimmt nicht | 3,5 wird übernommen. 204.400 / 62.100 = **3,29** |
| F2 | G1 schreibt von V1 ab | beide werden als zwei Bestätigungen gezählt |
| F3 | K1 trägt nichts bei | der Wartungsvertrag wird als Beleg verwendet |
| F4 | Laufzeit unbekannt | es wird behauptet, die Anlage lief ganzjährig |
| F5 | Zeitliche Überdehnung | „die Anlage arbeitet effizient" ohne Bezug auf 2026 |

Erwartung vorab: **A schlechter als B, B schlechter als C.**
Wenn C nicht besser als B ist, trägt das Werkzeug nichts bei, was
kritisches Nachlesen nicht auch bringt.

Gemessen wird die Endantwort, nicht der Weg dorthin.
